## Memilih Pelayan Mandiri yang Tepat untuk DeepSeek-R1 70B

Sebelum kita mula celup tangan dalam ujian kelajuan, pilih server yang betul tu memang penting gila. DeepSeek-R1 70B, walaupun model yang sangat cekap, tetap perlukan perkakasan yang kuat. Okay, apa yang penting nak tahu: RAM (sekurang-kurangnya 128GB adalah ideal untuk pastikan semua stabil), CPU multi-core yang pantas, dan yang paling penting, **kad grafik (GPU) dengan VRAM yang tinggi**. Untuk DeepSeek-R1 70B yang dah 'kecilkan' (quantised) ke `q4_k_m`, korang perlukan GPU NVIDIA dengan VRAM sekurang-kurangnya 24GB. Kad macam NVIDIA RTX 3090 atau RTX 4090 memang pilihan ramai, atau boleh guna kad siri A yang lagi berkuasa kalau beban kerja tu berat sangat.

Pilih penyedia server yang ada di Malaysia? Ini memang satu bonus besar! Ia akan pastikan latensi rendah, maksudnya data bergerak lagi laju antara korang dengan model AI tu. Untuk sistem operasi, Ubuntu Server LTS (contohnya, versi 22.04 LTS) adalah pilihan terbaik sebab stabil dan komuniti dia ramai, terutamanya untuk setup driver NVIDIA.

## Menyiapkan Persekitaran: Ollama dan Dependensi

Nak buat kerja running LLM secara lokal ni jadi senang sikit, kami guna Ollama. Ia alat yang ringkas tapi berkuasa, membolehkan korang 'tarik' (pull) dan jalankan macam-macam model LLM dengan beberapa perintah je. Untuk ujian ni, kami pakai **Ollama versi 0.1.32**.

### Langkah 1: Pasang Ollama

Langkah pertama, mestilah pasang Ollama kat server korang. Sambung ke server melalui SSH dan jalankan arahan ni. Penting gila, pastikan driver NVIDIA korang dah update dan berfungsi dengan elok kat server tu, sebab kalau tak, Ollama tak dapatlah nak guna kuasa kad grafik tu.

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

Proses ni biasanya cepat je. Bila dah siap, korang boleh check sama ada Ollama dah terpasang dengan betul. Nak info lanjut pasal install dan guna Ollama? Boleh tengok panduan kami yang lagi detail kat [cara setup Ollama untuk DeepSeek secara lokal](/posts/deepseek-ollama-local-setup/). Kalau ada masalah sikit-sikit, jangan panik, layari je laman web [rasmi Ollama](https://ollama.com/) untuk support terkini.

### Langkah 2: Muat Turun Model DeepSeek-R1 70B

Bila Ollama dah berjaya dipasang, langkah seterusnya barulah kita download model DeepSeek-R1 70B. Kami akan pakai versi `q4_k_m`, yang merupakan versi 'quantised'. Maksudnya, saiz model ni dah dioptimumkan untuk guna memori (VRAM) yang lebih efisien, jadi ia boleh jalan kat kad grafik dengan VRAM 24GB. Taip je perintah ni kat terminal korang:

```bash
ollama pull deepseek-r1-70b:q4_k_m
```

Proses ni, haa, mungkin makan masa sikit, dalam 20 hingga 60 minit, bergantung pada kelajuan internet server korang dan saiz model (memang besar, boleh cecah puluhan GB!). Sabar je lah, biarkan dia download sampai habis.

### Langkah 3: Jalankan Ujian Kelajuan Sebenar

Okay, masa untuk cabaran sebenar! Jalankan model dan bagi dia beberapa prompt untuk tengok macam mana laju dia. Korang boleh start dengan arahan ni:

```bash
ollama run deepseek-r1-70b:q4_k_m
```

Bila model dah loading, korang dah boleh mula sembang dengan dia. Nak ukur kelajuan? Kita akan bagi beberapa prompt contoh dan perhatikan berapa lama dia respon, dan berapa banyak token yang dia hasilkan setiap saat. Ini antara prompt yang korang boleh guna:

*   `Tulis ringkasan tentang cabaran ekonomi digital di Malaysia dalam 200 patah perkataan.`
*   `Jelaskan konsep tenaga boleh diperbaharui dalam konteks Malaysia, dalam 150 patah perkataan.`
*   `Berikan 5 idea perniagaan kecil yang boleh dimulakan dengan modal rendah di kawasan bandar.`

Perhatikan masa yang diambil oleh model untuk hasilkan jawapan penuh. Ulang je ujian ni beberapa kali dengan prompt lain-lain untuk dapatkan purata yang lagi ngam. Ingat ya, kualiti prompt kita pun main peranan penting; nak prompt yang lagi power? Jom [belajar asas-asas prompt yang efektif di sini](/posts/deepseek-prompt-basics/) untuk hasil yang superb!

## Tips Optimumkan Prestasi DeepSeek-R1 70B

Nak pastikan korang dapat yang paling best dari DeepSeek-R1 70B korang? Meh sini saya bagi tips-tips ni:

*   **Guna Model Quantised:** Sentiasa pilih versi model yang dah diringkaskan (contohnya `q4_k_m`, `q5_k_m`). Ini boleh buat model tu muat dalam VRAM yang lebih kecil dan jalan lagi efisien tanpa hilang banyak sangat kualiti.
*   **Kemas Kini Driver GPU:** Driver NVIDIA korang tu mesti sentiasa yang terkini. Driver lama boleh jadi punca utama masalah prestasi atau tak serasi.
*   **Pantau Penggunaan Sumber:** Guna je alat macam `nvidia-smi` untuk pantau penggunaan VRAM dan suhu GPU. Ini bantu korang kenal pasti kalau ada masalah atau kalau server korang tu dah 'penat'.
*   **Pertimbangkan Pelbagai GPU:** Untuk kerja yang memang banyak gila atau kalau nak jalankan beberapa model serentak, melabur dalam server dengan banyak kad grafik adalah langkah seterusnya yang logik.
*   **Fahami Limitasi:** Setiap model ada hadnya. Kalau korang bercadang nak guna DeepSeek untuk aplikasi komersial, penting untuk fahami [had dan penggunaan API DeepSeek](/posts/deepseek-api-key-and-limits/) kalau korang nak beralih ke versi awan mereka, atau sekurang-kurangnya batasan model yang dijalankan secara lokal.

## Soalan Lazim

Okay, ini antara soalan-soalan yang selalu orang tanya pasal guna DeepSeek-R1 70B kat server sendiri:

**Q1: Apa benda DeepSeek-R1 70B ni sebenarnya?**

DeepSeek-R1 70B ni adalah model bahasa besar (LLM) berskala 70 bilion parameter yang dibangunkan oleh DeepSeek AI. Ia dilatih dengan data yang sangat luas dan direka untuk buat macam-macam kerja berkaitan pemprosesan bahasa, macam hasilkan teks kreatif, ringkaskan dokumen, terjemah bahasa, dan jawab soalan. Ini salah satu model 'open-weight' yang prestasi tinggi dan boleh dihoskan sendiri, jadi ia bagi alternatif kepada solusi berasaskan awan. Korang boleh explore lebih lanjut kat [platform rasmi DeepSeek](https://platform.deepseek.com/).

**Q2: Wajib ke ada server sendiri untuk jalankan model ni?**

Untuk prestasi yang mantap, stabil, dan kawalan penuh ke atas data korang, ya, server sendiri memang sangatlah disyorkan. DeepSeek-R1 70B ni perlukan sumber perkakasan yang agak besar, terutamanya VRAM. Laptop atau PC desktop biasa mungkin tak cukup memori GPU untuk jalankan model sebesar ini dengan efisien. Server sendiri sediakan persekitaran yang stabil dan berkuasa yang memang diperlukan.

**Q3: Model ni sesuai ke untuk PKS kat Malaysia?**

Sangat-sangat sesuai! Bagi PKS kat Malaysia yang mementingkan kawalan ke atas data sensitif, keselamatan maklumat, dan latensi yang paling rendah, jalankan AI secara lokal pada server sendiri adalah pilihan yang sangat strategik. Ia boleh diguna untuk macam-macam tujuan, contohnya automasi sokongan pelanggan, analisis dokumen perniagaan dalaman, hasilkan draf laporan, atau nak buat chatbot khas untuk industri korang tanpa perlu hantar data ke server luar negara. Kalau nak tahu lagi, boleh tengok [bagaimana Gemini Workflow boleh bantu PKS](/posts/gemini-workflow-for-smes/).

**Q4: Boleh ke saya guna kad grafik gaming biasa?**

Boleh, tapi kena tengoklah berapa banyak VRAM kad grafik tu ada. Kad grafik gaming kelas atas macam NVIDIA RTX 3090 atau RTX 4090, yang ada 24GB VRAM, memang cun untuk jalankan DeepSeek-R1 70B versi yang dah diringkaskan. Kalau kad dengan VRAM rendah sikit, mungkin kena guna model yang lebih kecil atau versi 'quantisation' yang lagi agresif, tapi ini boleh je jejaskan sikit prestasi atau kualiti output.

**Q5: Apa beza DeepSeek-R1 70B dengan model AI lain yang popular?**

DeepSeek-R1 70B ni model 'open-weight'. Maksudnya, kod dan 'berat' model dia boleh diakses dan dijalankan sendiri oleh pengguna. Ini beza dengan model proprietari macam GPT-4 (OpenAI) atau Gemini (Google) yang selalunya boleh diakses melalui API berasaskan awan je. Kelebihan model 'open-weight' ni adalah korang ada kawalan penuh ke atas infrastruktur, privasi data, dan boleh ubah suai model ikut keperluan spesifik korang tanpa bergantung kepada pihak ketiga. Potensi untuk jimat kos jangka panjang pun ada.
