## Langkah 2: Tulis Kod Automasi Untuk Hasilkan Video

Okay, sekarang kita masuk ke bab teknikal sikit. Kita akan guna Python untuk 'bersembang' dengan DeepSeek API. Konsepnya mudah: korang hantar skrip dan prompt tadi kat API, dan API akan pulangkan balik URL video yang dah siap.

```python
import requests
import json
import time

DEEPSEEK_API_KEY = "PASTE_API_KEY_ANDA_DI_SINI"
DEEPSEEK_ENDPOINT = "https://platform.deepseek.com/api/v1/digital-human-video-create" # Ini adalah contoh endpoint, sila semak dokumentasi rasmi DeepSeek

def create_digital_human_video(script_text, prompt_data):
    headers = {
        "Authorization": f"Bearer {DEEPSEEK_API_KEY}",
        "Content-Type": "application/json"
    }

    payload = {
        "script": script_text,
        "prompt": prompt_data
    }

    print("Menghantar permintaan ke DeepSeek API...")
    try:
        response = requests.post(DEEPSEEK_ENDPOINT, headers=headers, data=json.dumps(payload))
        response.raise_for_status() # Akan keluarkan exception jika status kod HTTP adalah ralat
        result = response.json()
        print(f"Permintaan berjaya. ID Video: {result.get('video_id')}")
        return result.get('video_url_await_processing') # Atau apa-apa URL status yang DeepSeek berikan
    except requests.exceptions.RequestException as e:
        print(f"Ralat ketika memanggil DeepSeek API: {e}")
        print(f"Response body: {response.text}")
        return None

# Skrip dan Prompt yang anda sediakan
my_script = "Hai semua, selamat datang ke saluran kami! Hari ini kita akan bincangkan perkembangan teknologi AI yang paling hangat di Malaysia. Jangan lupa like dan subscribe!"

  "character_gender": "female",
  "character_age": "30s",

  "emotion": "happy",
  "background_scene": "modern studio"
}

```
