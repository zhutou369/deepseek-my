## Isi Kandungan

### Langkah 1: Menyiapkan Persekitaran Lokal

Langkah pertama, mari kita pastikan sistem korang dah sedia untuk DeepSeek dan Vector DB.

1.  **Pasang Ollama**: Mula-mula, download dan install Ollama dari website rasmi dorang (ollama.com). Benda ni penting sebab ia akan bantu korang run model bahasa besar secara lokal.
2.  **Muat Turun Model DeepSeek**: Lepas Ollama dah install, buka terminal dan jalankan command `ollama pull deepseek-coder:latest`. (Atau model DeepSeek lain yang korang nak guna). Proses ni akan tarik model tu ke server korang.
3.  **Pilih & Pasang Vector DB**: Untuk panduan ni, kita akan guna ChromaDB sebab ia senang nak start. Install ChromaDB pakai pip: `pip install chromadb`. Jangan lupa install jugak pakej Python yang penting macam `sentence-transformers` untuk tukar teks jadi vektor.

### Langkah 2: Membina Pangkalan Data Vektor Anda

Dah siap DeepSeek dengan Vector DB? Okay, sekarang masa untuk isi Vector DB korang dengan data-data penting PKS.

1.  **Kumpul Data**: Kumpulkan semua dokumen atau teks kritikal yang korang nak semak silang. Contohnya, invois, perjanjian pelanggan, senarai produk, atau memo dalaman. Pastikan data ni bersih dan dalam format yang mesin boleh baca.
2.  **Tukar Teks ke Vektor**: Guna model 'embedding' (biasanya datang sekali dengan `sentence-transformers`) untuk tukar setiap kepingan teks korang jadi vektor nombor. Vektor-vektor ni nanti akan disimpan dalam ChromaDB. Ni ada contoh kod Python ringkas:
    ```python
    from langchain_community.document_loaders import TextLoader
    from langchain_community.embeddings.ollama import OllamaEmbeddings
    from langchain_community.vectorstores import Chroma
    from langchain.text_splitter import CharacterTextSplitter
    
    # Muat turun dokumen
    loader = TextLoader("data_pks_anda.txt")
    documents = loader.load()
    
    # Pisahkan dokumen menjadi bahagian yang lebih kecil
    text_splitter = CharacterTextSplitter(chunk_size=1000, chunk_overlap=0)
    docs = text_splitter.split_documents(documents)
    
    # Cipta embedding menggunakan Ollama (DeepSeek)
    embeddings = OllamaEmbeddings(model="deepseek-coder:latest")
    
    # Cipta ChromaDB dari dokumen dan embedding
    vectorstore = Chroma.from_documents(documents=docs, embedding=embeddings, persist_directory="./chroma_db")
    vectorstore.persist()
    ```
3.  **Simpan Vektor**: Lepas data korang dah tukar jadi vektor, simpan ia dalam ChromaDB. Proses ni mungkin ambil masa sikit bergantung pada berapa banyak data korang. Penting untuk simpan direktori ChromaDB korang kat tempat yang selamat ya.

### Langkah 3: Menggunakan DeepSeek untuk Semak Silang

Baik, sekarang DeepSeek dan Vector DB korang dah terisi, jom kita mula buat pertanyaan dan jalankan semak silang.

1.  **Muat Semula Vector DB**: Setiap kali korang nak buat pertanyaan, kena muat semula pangkalan data vektor korang.
2.  **Tanya DeepSeek**: Gunakan DeepSeek melalui Ollama API tempatan korang untuk tanya soalan pasal data yang nak disahkan. Contohnya, 'Harga produk X dalam invois ni sama ke dengan senarai harga rasmi?'
3.  **Cari dalam Vector DB**: Berdasarkan pertanyaan DeepSeek, cari maklumat relevan dalam Vector DB. Korang boleh guna DeepSeek untuk jana pertanyaan carian yang lebih spesifik untuk Vector DB, lepas tu bandingkan hasilnya. Contoh konsep kod:
    ```python
    from langchain_community.llms import Ollama
    from langchain_community.vectorstores import Chroma
    from langchain_community.embeddings.ollama import OllamaEmbeddings
    
    # Muat semula ChromaDB
    embeddings = OllamaEmbeddings(model="deepseek-coder:latest")
    vectorstore = Chroma(persist_directory="./chroma_db", embedding_function=embeddings)
    
    # Inisialisasi DeepSeek melalui Ollama
    llm = Ollama(model="deepseek-coder:latest")
    
    # Pertanyaan untuk semak silang
    query_text = "Harga produk 'Laptop X' dalam invois terkini adalah RM3500. Adakah ini betul berdasarkan data produk utama?"
    
    # Cari dokumen berkaitan dari Vector DB
    relevant_docs = vectorstore.similarity_search(query_text, k=3)
    context = " ".join([doc.page_content for doc in relevant_docs])
    
    # Hantar ke DeepSeek untuk analisis
    prompt = f"Berdasarkan konteks berikut: {context}. Sila sahkan samada harga 'Laptop X' RM3500 adalah betul mengikut data produk. Berikan jawapan ringkas."
    response = llm.invoke(prompt)
    print(response)
    ```
4.  **Analisis dan Tindakan**: DeepSeek akan analisis konteks dari Vector DB dan bagi jawapan. Kalau ada benda tak sama, sistem ni boleh bagitahu korang untuk tindakan seterusnya. Ini memang bantu PKS cepat kesan data yang tak selaras dan baiki dia. Ingat, sikit ilmu pasal [cara nak 'prompt' DeepSeek dengan betul](/posts/deepseek-prompt-basics/) memang akan bantu korang dapat hasil terbaik.

## Soalan Lazim (FAQ)

### S1: Adakah sistem ini selamat untuk data sensitif PKS saya?

Ya, memang selamat! Salah satu sebab utama guna DeepSeek secara on-premise dengan Vector DB ialah data korang kekal dalam rangkaian (network) sendiri. Ini kurangkan risiko data bocor jauh lebih banyak berbanding kalau guna servis cloud pihak ketiga. Korang ada kawalan penuh atas keselamatan data, baik fizikal mahupun siber.

### S2: Berapa kos untuk menyiapkan sistem ini?

Kos tu ikutlah infrastruktur korang yang sedia ada. Kalau dah ada server dengan kad grafik power, kos mungkin rendah sikit. Pelaburan utama selalunya untuk perkakasan (kalau tak ada lagi), dan masa untuk setup serta konfigurasi. Perisian DeepSeek (guna Ollama) dan Vector DB (macam ChromaDB) ni kebanyakannya open-source atau percuma untuk kegunaan lokal.

### S3: Adakah saya perlukan kepakaran teknikal yang tinggi untuk mengendalikan ini?

Untuk permulaan, memang kena ada sikit basic teknikal, terutamanya dalam install software, configure server, dan tulis skrip Python asas. Tapi, bila sistem dah jalan, operasi harian boleh jadi lebih user-friendly dengan interface yang sesuai. Korang boleh juga dapatkan bantuan dari profesional IT tempatan kalau perlu.

### S4: Bagaimana pula jika saya nak semak silang data yang tidak berstruktur, seperti e-mel atau dokumen PDF?

DeepSeek dan Vector DB memang handal bab data tak berstruktur ni. Korang cuma perlu buat 'data preprocessing' dulu untuk extract teks dari e-mel atau PDF (boleh guna library macam `PyPDF2` atau `email` dalam Python), lepas tu baru tukarkan teks tu jadi vektor dan masukkan ke dalam Vector DB. DeepSeek kemudian boleh proses konteks dari teks yang dah diekstrak ni.

### S5: Bolehkah DeepSeek membantu membetulkan kesilapan data secara automatik?

DeepSeek boleh cadangkan pembetulan atau highlight bahagian yang bercanggah. Walaupun secara teknikal boleh set untuk betulkan data automatik, untuk data yang kritikal, saya rasa lebih baik kalau sentiasa ada semakan manusia. DeepSeek ni boleh jadi macam 'pembantu' yang efisien, tunjukkan kat mana masalahnya, dan bagi cadangan, tapi keputusan akhir tetap di tangan korang.
