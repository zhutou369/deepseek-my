## Kenapa Nak Tune DeepSeek Secara Tempatan?

Ada beberapa sebab yang *power* kenapa PKS patut pertimbangkan latih DeepSeek dengan data sendiri kat komputer. Pertama, **privasi dan keselamatan data**. Kalau bisnes korang handle maklumat pelanggan yang sensitif, rekod kewangan syarikat, atau strategi rahsia, *confirm* korang tak nak data tu berlegar-legar kat server orang lain. Dengan fine-tuning secara on-premise, semua data tu kekal dalam rangkaian korang je.

Kedua, **boleh ubah suai ikut citarasa kita**. Model DeepSeek yang standard memang dah *power*, tapi dia belajar dari data umum yang luas. Untuk kerja yang *super* spesifik – contohnya, tulis draf e-mel guna terma khas industri korang, analisis laporan jualan ikut format syarikat, atau jawab soalan pelanggan berasaskan manual produk – model standard mungkin tak seberapa cekap. Model yang dah 'belajar' data korang sendiri, memang lain macam hasilnya.

Ketiga, **kita pegang kawalan sepenuhnya**. Korang boleh tentukan versi model, infrastruktur, dan cara nak latih dia. Ini memang beri kebebasan untuk eksperimen dan ubah suai proses ikut apa yang bisnes korang betul-betul perlukan. *Memang syok!*

## DeepSeek Versi Mana Yang Sesuai?

Untuk tujuan fine-tuning secara tempatan, terutamanya bila kita ada kekangan kad grafik kat PKS, model DeepSeek yang lebih kecil dan senang nak urus adalah pilihan paling mantap. Saya sendiri pernah uji cuba beberapa versi, dan pada masa ni (awal tahun 2024), saya dapati DeepSeek-LLM 7B-Chat v1.5 atau DeepSeek-Coder-V2 7B memang *ngam* untuk permulaan. Model-model ni bagi keseimbangan prestasi dan guna sumber yang baik. Kiranya, cukup ringan nak jalan kat kad grafik biasa macam NVIDIA RTX 3060 atau 4060 ke atas, yang ada VRAM (memori kad grafik) sekitar 8GB atau lebih.

## Langkah 1: Sediakan Data Proprietari Anda

Langkah pertama dan paling penting sekali adalah penyediaan data. Ingat, kualiti data akan tentukan kualiti model yang kita dapat. Data korang kena bersih, relevan, dan dalam format yang sesuai. Biasanya, format JSON Lines (`.jsonl`) adalah pilihan terbaik dan paling mudah.

Setiap baris dalam fail `.jsonl` korang akan jadi satu contoh latihan. Contohnya:

```json
{"prompt": "Tulis draf e-mel untuk memperkenalkan produk baru X kepada pelanggan PKS kami.", "completion": "Assalamualaikum Tuan/Puan, Kami ingin memperkenalkan produk X..."}
```

Atau jika menggunakan format percakapan:

```json
{"messages": [{"role": "user", "content": "Apakah polisi cuti tahunan syarikat?"}, {"role": "assistant", "content": "Cuti tahunan asas adalah 14 hari..."}]}
```

Pastikan data korang konsisten dan tak ada bias yang tak diingini. Proses ni mungkin makan masa sikit untuk bersihkan dan susun elok-elok. Oh ya, walaupun kita tak cakap pasal prompt engineering sangat kat sini, faham [prinsip asas prompt engineering DeepSeek](/posts/deepseek-prompt-basics/) boleh tolong korang susun data latihan jadi lebih efektif tau!

## Langkah 3: Proses Fine-Tuning Model DeepSeek

Lepas data dan persekitaran dah *ready*, tiba masa untuk proses fine-tuning. Kita akan guna teknik LoRA (Low-Rank Adaptation) yang sangat cekap. Teknik ni boleh latih model tanpa perlu VRAM yang terlalu tinggi, *ngam* sangatlah untuk PKS yang mungkin ada kad grafik yang lebih sederhana.

Berikut adalah contoh skrip Python asas untuk fine-tuning guna `transformers` dan `peft`. Korang perlu sesuaikan dengan laluan data dan nama model korang:

```python
from datasets import load_dataset
from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments, Trainer
from peft import LoraConfig, get_peft_model
import torch

# 1. Muatkan dataset anda
dataset = load_dataset('json', data_files='laluan/ke/data_latihan_anda.jsonl')

# 2. Muatkan model asas DeepSeek dan tokenizer
model_name = "deepseek-ai/deepseek-llm-7b-chat-v1.5"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    torch_dtype=torch.bfloat16, # Gunakan bfloat16 jika kad grafik anda menyokong
    device_map="auto" # Menguruskan beban VRAM secara automatik
)

# Konfigurasi LoRA
lora_config = LoraConfig(
    r=16, # rank LoRA
    lora_alpha=32, # alpha LoRA
    target_modules=["q_proj", "v_proj"], # Modul untuk diaplikasikan LoRA
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM"
)
model = get_peft_model(model, lora_config)

# 3. Pra-pemprosesan data (tokenize)
def tokenize_function(examples):
    # Tambah logic formatasi prompt/jawapan anda di sini
    # Contoh mudah: gabungkan prompt dan completion
    texts = [f"### User:\n{p}\n### Assistant:\n{c}\n" for p, c in zip(examples['prompt'], examples['completion'])]
    return tokenizer(texts, truncation=True, max_length=512)

tokenized_datasets = dataset.map(tokenize_function, batched=True)

# 4. Tetapkan argumen latihan
training_args = TrainingArguments(
    output_dir="./deepseek_tuned",
    per_device_train_batch_size=2, # Sesuaikan dengan VRAM anda
    gradient_accumulation_steps=4, # Menaikkan batch size efektif
    learning_rate=2e-4,
    num_train_epochs=3,
    logging_steps=10,
    save_steps=500,
    fp16=True # Gunakan fp16 jika VRAM terhad (perlu torch 1.6+ & driver Nvidia)
)

# 5. Mula latihan
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_datasets['train'],
    tokenizer=tokenizer
)

trainer.train()

# 6. Simpan model yang telah ditune
model.save_pretrained("./deepseek_tuned_model")
tokenizer.save_pretrained("./deepseek_tuned_model")
```

Skrip kat atas ni cuma asas je. ## Memantau dan Menilai Prestasi

Masa proses latihan, korang akan nampak log kat terminal yang tunjuk `loss` (kerugian) model tu menurun. Ini petanda baik tau! Lepas latihan dah *settle*, korang kena uji model korang dengan data yang dia tak pernah jumpa lagi (`validation set` atau `test set`).

Korang boleh guna model yang dah ditune tadi dengan Ollama. Cuma eksport model korang ke format yang serasi dengan Ollama (guna `llama.cpp` atau `merge_peft_adapter` dari `transformers` untuk gabungkan adapter LoRA dengan model asas) dan kemudian import ke Ollama. Minggu lepas saya naik taraf pelayan saya dan saya terkejut betapa jauhnya kemajuan `unsloth` dan `lorax` dalam mempercepatkan proses ini. *Memang jimat masa banyak!*

Uji model dengan soalan atau tugasan yang spesifik untuk bisnes korang dan bandingkan prestasinya dengan model DeepSeek yang asal. Korang patut nampak peningkatan yang ketara dalam ketepatan dan relevansi jawapan.

## Tips Tambahan Untuk PKS

*   **Mula dengan Data Kecil**: Jangan terus melatih dengan berjuta data. Mula dengan sampel kecil dulu untuk pastikan skrip korang berfungsi dan model mula belajar. *Start slow, tapi steady!*
*   **Gunakan Perpustakaan Cekap**: Pertimbangkan `unsloth` atau `lorax` untuk fine-tuning LoRA. Ia direka untuk lebih pantas dan guna VRAM dengan lebih cekap. Ini boleh jimatkan masa dan kos, macam kalau korang kena fikirkan [limitasi API DeepSeek](/posts/deepseek-api-key-and-limits/) pulak nanti.
*   **Jaga Keamanan Fizikal**: Sebab data sensitif korang disimpan secara tempatan, pastikan server korang berada di tempat yang selamat dan ada kawalan akses fizikal. Penting ni, macam nak jaga duit dalam bank!
*   **Backup Data**: Sentiasa buat salinan sandar (backup) data latihan dan model yang dah dilatih. Bencana boleh berlaku bila-bila masa, jadi berjaga-jaga tu bagus. Ini penting juga untuk [memulakan perjalanan AI lokal untuk PKS anda](/posts/getting-started-with-local-ai-for-pks/) secara selamat.
*   **Libatkan Pakar**: Kalau rasa proses ni terlalu teknikal sangat, apa kata dapatkan nasihat dari pakar AI tempatan? Pelaburan awal ni boleh jimatkan masa dan sumber korang dalam jangka masa panjang. Tak perlu pening kepala sorang-sorang!

## Soalan Lazim

**S1: Perlu kad grafik mahal ke untuk fine-tuning DeepSeek 7B?**

Untuk DeepSeek 7B menggunakan teknik LoRA, kad grafik macam NVIDIA RTX 3060 (12GB VRAM) atau RTX 4060 Ti (16GB VRAM) dah memadai. Kalau VRAM lebih rendah (8GB), korang boleh cuba teknik kuantisasi (contohnya 4-bit) yang mengurangkan penggunaan memori, tapi ini mungkin kurangkan sikit prestasi model. Lebih banyak VRAM, lebih besar `batch_size` yang boleh korang guna, dan ini boleh mempercepatkan proses latihan. Jadi, tak semestinya kena pakai yang paling mahal pun.

**S2: Data saya tak banyak, boleh ke buat fine-tuning?**

Ya, boleh sangat! Teknik macam LoRA ni direka untuk berfungsi dengan baik walaupun dengan jumlah data latihan yang agak terhad (contohnya, beberapa ratus hingga ribu contoh). Kualiti data lebih penting daripada kuantiti, terutamanya untuk fine-tuning. Pastikan setiap contoh dalam dataset korang adalah berkualiti tinggi dan relevan dengan tugas yang korang inginkan.

**S3: Selamat tak data saya bila fine-tuning secara tempatan?**

Fine-tuning secara tempatan adalah salah satu cara paling selamat untuk melindungi data proprietari korang. Data korang tak perlu keluar dari rangkaian fizikal syarikat dan tak dihantar ke pelayan pihak ketiga. Ini bagi korang kawalan penuh ke atas keselamatan dan privasi data. Walau macam mana pun, korang masih perlu pastikan pelayan korang dilindungi dengan langkah keselamatan IT yang standard (firewall, antivirus, kawalan akses).

**S4: Boleh guna model DeepSeek yang ditune ni untuk tugas apa?**

Dengan model DeepSeek yang ditune, korang boleh automatikkan pelbagai tugas spesifik bisnes. Contohnya, menjawab soalan lazim pelanggan berdasarkan pangkalan pengetahuan korang, menjana draf laporan atau ringkasan mesyuarat, bantu tulis bahan pemasaran dengan gaya bahasa syarikat korang, atau bantu penganalisis data dalam faham corak data internal dengan lebih baik. Potensinya sangat luas, bergantung pada data yang korang latih.

**S5: Apa beza fine-tuning secara tempatan dengan menggunakan API DeepSeek di awan?**

Beza utamanya adalah kawalan dan privasi data. Apabila korang guna API DeepSeek (atau API LLM lain), data input korang dihantar ke pelayan DeepSeek (atau penyedia awan). Walaupun mereka ada polisi privasi yang ketat, korang tak ada kawalan mutlak ke atas lokasi data. Fine-tuning secara tempatan pula pastikan data dan model kekal sepenuhnya dalam infrastruktur IT korang, bagi privasi dan keselamatan data yang maksimum, sesuai untuk PKS yang sangat mementingkan kerahsiaan maklumat.

**S6: Berapa anggaran kos untuk setup fine-tuning secara tempatan ni?**

Kosnya sangat bergantung pada perkakasan yang korang pilih. Kalau dah ada PC gaming high-end dengan GPU NVIDIA yang kuat (contoh RTX 3060/4060 ke atas), korang mungkin cuma perlu labur pada masa untuk setup software dan data. Kalau nak beli server baru, kosnya boleh dari beberapa ribu hingga puluhan ribu ringgit, bergantung pada spesifikasi. Tapi, fikirkan ni sebagai pelaburan jangka panjang untuk kawalan data dan kustomisasi AI syarikat korang. Lebih murah dari langgan API secara berterusan kalau usage tinggi!

Memulakan perjalanan fine-tuning model DeepSeek secara tempatan mungkin nampak mencabar sikit pada mulanya. Tapi, dengan persediaan yang betul dan sedikit kesabaran, PKS korang boleh bina sistem AI yang disesuaikan khas untuk keperluan dan data syarikat. Ini adalah langkah besar ke arah automasi pintar dan daya saing yang lebih tinggi dalam pasaran Malaysia yang makin kompetitif!
