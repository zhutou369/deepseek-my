Cun! Langkah seterusnya, kita setup proksi atau VPN kat server tu. Ini penting supaya semua trafik API DeepSeek korang akan lalu ikut IP dedikasi tu. Untuk panduan ni, kami fokus pada proksi SOCKS5 sebab ia ringan dan memang berkesan. 1.  **Log Masuk ke Pelayan Anda:** Guna SSH untuk masuk ke VPS korang. ```bash ssh user@your_dedicated_ip ``` 2.  **Pasang `dante-server` (Proksi SOCKS5):** `dante-server` ni perisian proksi SOCKS5 yang ramai orang pakai. Pasang je kat server Linux korang. ```bash sudo apt update sudo apt install dante-server -y ``` 3.  **Konfigurasi `dante-server`:** Kita akan edit fail konfigurasi dia, `/etc/danted.conf`. Tapi sebelum tu, buatlah backup dulu fail asal, kot-kot ada tersalah buat nanti. ```bash sudo mv /etc/danted.conf /etc/danted.conf.bak sudo nano /etc/danted.conf ``` Masukkan konfigurasi asas ni. Gantikan `your_dedicated_ip` dengan IP server korang, dan `your_local_network_ip_range` kalau korang nak hadkan akses dari rangkaian tertentu. ``` logoutput: syslog internal: your_dedicated_ip port=1080 external: your_dedicated_ip clientmethod: none socksmethod: none user.privileged: root user.unprivileged: nobody client pass { from: 0.0.0.0/0 to: 0.0.0.0/0 log: error connect disconnect } socks pass { from: 0.0.0.0/0 to: 0.0.0.0/0 log: error connect disconnect } ``` Nak lebih selamat? Korang boleh tambah pengesahan pengguna (authentication). Dengan cara ni, cuma orang yang ada username dan password je boleh guna proksi ni. ``` # Tambah baris ini di bawah 'socksmethod: none' socksmethod: username none # Cipta pengguna dante sudo useradd -r -s /bin/false danteuser sudo passwd danteuser # Set kata laluan ``` Lepas tu, dalam `danted.conf` tukar `socksmethod: none` kepada `socksmethod: username`. Untuk info lebih detail pasal pengesahan dan keselamatan, boleh refer dokumentasi `dante-server` tau. Masa *saya sendiri* uji konfigurasi ni, saya rasa `dante-server` ni memang lagi senang nak setup untuk permulaan, berbanding pilihan lain yang lebih rumit, terutamanya bagi korang yang mungkin tak berapa familiar sangat dengan konfigurasi rangkaian. 4.  **Mulakan Semula `dante-server`:** ```bash sudo systemctl restart danted sudo systemctl enable danted sudo systemctl status danted ``` 5.  **Konfigurasi Firewall (UFW):** Penting ni, pastikan port 1080 (atau apa-apa port yang korang pilih) dibuka untuk akses. Kalau tak buka, memang takde siapa boleh sambung ke proksi korang nanti. ![Komponen mikrocip yang diletakkan pada papan litar tercetak menunjukkan pemproses dan memori](https://images.unsplash.com/photo-1581091226825-a6a2a5aee158?q=80&w=600&auto=format&fit=crop) *Imej 2: Paparan rapat mikrocip yang berfungsi sebagai otak di belakang operasi pelayan anda, memproses setiap permintaan API melalui IP dedikasi anda.* ### Langkah 3: Integrasi dengan Aplikasi DeepSeek Anda Last but not least, korang kena bagitau aplikasi korang untuk guna proksi yang baru setup ni. Jangan risau, kebanyakan bahasa coding dan library HTTP memang dah support konfigurasi proksi ni. **Untuk Aplikasi Python (guna library `requests`):** ```python import requests proxies = { 'http': 'socks5://danteuser:your_password@your_dedicated_ip:1080', 'https': 'socks5://danteuser:your_password@your_dedicated_ip:1080' } # Contoh panggilan API DeepSeek # Korang kena gantikan dengan URL API DeepSeek yang betul-betul punya # dan pastikan korang ada API key yang sah. # Untuk info lanjut pasal API DeepSeek, boleh la check panduan ni: # [Panduan Asas Memulakan API DeepSeek](https://platform.deepseek.com/) api_url = "https://api.deepseek.com/v1/chat/completions" headers = {"Authorization": "Bearer YOUR_DEEPSEEK_API_KEY"} data = {"model": "deepseek-chat", "messages": [{"role": "user", "content": "Hello, DeepSeek!"}]} try: response = requests.post(api_url, headers=headers, json=data, proxies=proxies, timeout=30) response.raise_for_status() # Akan keluarkan error kalau status HTTP tak okay print(response.json()) except requests.exceptions.RequestException as e: print(f"Ada error masa buat permintaan: {e}") ``` **Untuk Aplikasi yang Menggunakan Pembolehubah Persekitaran:** Korang boleh set pembolehubah persekitaran `HTTP_PROXY` dan `HTTPS_PROXY` sebelum run aplikasi korang. Cara ni memang berguna untuk banyak tool CLI atau library yang akan kesan proksi secara automatik. ```bash export HTTP_PROXY="socks5://danteuser:your_password@your_dedicated_ip:1080" export HTTPS_PROXY="socks5://danteuser:your_password@your_dedicated_ip:1080" # Lepas tu, jalan kan la aplikasi korang python your_deepseek_app.py ``` Dah selesai integrasi?
