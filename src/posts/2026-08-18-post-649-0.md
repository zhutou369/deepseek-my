## Tutorial: Ramal Harga Kereta Terpakai dengan DeepSeek

Jom kita terjah macam mana korang boleh guna DeepSeek untuk ramal harga kereta terpakai. Mungkin nampak macam teknikal sikit pada mulanya, tapi dengan panduan ni, ia akan jadi lebih mudah. ### Langkah 1: Kumpul dan Sedia Data Anda

Ok, langkah paling penting sekali adalah kumpul data kereta terpakai. Korang perlukan data sejarah jualan yang lengkap, yang ada ciri-ciri kereta dan harga jualan terakhirnya. Senang cerita, kena ada maklumat macam ni:

*   **Data Kena Ada:** Jenama, Model, Tahun Dibuat, Perbatuan (Mileage), Jenis Gearbox, Warna, Kondisi (macam mana keadaan kereta: cemerlang, baik, sederhana), Lokasi Jualan, dan Harga Jualan sebenar.
*   **Nak Cari Data Kat Mana?** Korang boleh dapatkan dari portal jualan kereta terpakai yang popular kat Malaysia (macam Mudah.my atau Carlist.my), atau kalau ada akses, dari peniaga-peniaga kereta. Ada juga data terbuka kalau bertuah. Satu benda yang paling *crucial*: pastikan data korang bersih daripada maklumat yang salah atau tak lengkap. Proses *data cleaning* ni memang kena buat betul-betul, kalau tak, nanti ramalan DeepSeek pun jadi 'kelaut'.

*Bayangkan ni:* Korang tengah tengok skrin komputer yang penuh dengan data dalam format spreadsheet (CSV atau Excel). Setiap baris tu satu kereta, dan setiap kolum tu ciri-ciri kereta tu, termasuk lajur paling hujung sekali untuk 'Harga Jualan'. Pastikan semua tajuk kolum terang dan jelas, dan datanya pun sama jenis (konsisten) tau.

### Langkah 2: Sediakan Persekitaran DeepSeek

Sekarang, macam mana nak buat DeepSeek ni bersedia untuk kerja? Korang ada dua cara utama:

*   **Guna API DeepSeek:** Ini cara paling senang dan cepat. Korang cuma perlu daftar kat [platform.deepseek.com](https://platform.deepseek.com/) untuk dapatkan kunci API. Lepas tu, korang boleh guna library Python macam `requests` atau SDK DeepSeek untuk 'cakap' dengan model ni. Ingat, penting sangat untuk faham [macam mana nak buat prompt DeepSeek yang efektif](/posts/deepseek-prompt-basics/) supaya dapat hasil yang superb!
*   **Install DeepSeek Secara Lokal Guna Ollama:** Kalau korang jenis yang suka kawalan penuh dan tak nak bergantung pada internet atau ada had API, korang boleh [pasang DeepSeek kat komputer sendiri pakai Ollama](/posts/deepseek-ollama-local-setup/). Tapi, korang kena ada kad grafik (GPU) yang cukup power kat PC atau server korang. Walaupun ia memerlukan sedikit usaha awal, fleksibiliti yang ditawarkan memang berbaloi.

*Cuba bayangkan:* Korang tengah tengok skrin terminal arahan atau VS Code (IDE popular tu). Kat situ ada kod Python ringkas untuk panggil API DeepSeek atau muatkan model DeepSeek melalui Ollama. Kod tu akan tunjuk cara nak setup kunci API korang dan contoh macam mana nak hantar data untuk diproses.

### Langkah 3: Latih atau Fine-Tune Model DeepSeek

Supaya ramalan DeepSeek ni jadi tepat, dia kena 'belajar' dulu dari data kereta terpakai yang korang dah kumpul tadi. Proses ni kita panggil *fine-tuning* atau latihan model. Ada dua cara yang biasa digunakan:

*   **Cara #1: Fine-Tuning (Latih Semula):** Korang boleh ambil model DeepSeek yang dah sedia dilatih, lepas tu 'ajar' dia lagi guna set data kereta terpakai korang sendiri. Ia macam tunjuk kat DeepSeek contoh input (ciri-ciri kereta) dan output yang betul (harga jualan). Ini bantu dia 'adjust' *setting* dalamannya untuk buat ramalan yang lagi jitu. Banyak platform AI atau API DeepSeek sediakan kemudahan *fine-tuning* yang boleh diprogramkan ni.
*   **Cara #2: Pendekatan Few-Shot Learning:** Kalau data korang tak banyak sangat, boleh cuba cara ni. Korang cuma perlu letakkan beberapa contoh data dalam *prompt* korang masa tanya DeepSeek. Ia macam bagi sedikit 'hint' kat model tu untuk panduan ramalan. Cara ni tak sekuat *fine-tuning* tapi sesuai kalau nak dapatkan hasil awal dengan cepat.

*Bayangkan:* Korang tengah tengok skrin *dashboard* kat web atau command line yang tunjuk proses *fine-tuning* berjalan. Korang akan nampak parameter macam *learning rate* (berapa cepat model belajar), bilangan *epoch* (berapa kali model baca data), dan laporan kemajuan yang tunjuk nilai *loss* model makin turun. Itu petanda DeepSeek tengah belajar dengan baik! Kalau guna *few-shot*, korang nampak *prompt* yang panjang dengan beberapa contoh kereta dan harganya sebelum soalan sebenar muncul.

### Langkah 4: Minta Ramalan Harga

Dah siap *fine-tune* atau *setup*? Bagus! Sekarang masa untuk DeepSeek buat kerja dia. Korang boleh terus minta ramalan harga untuk kereta baru yang korang nak jual atau beli. Caranya senang je, cuma perlu bagi DeepSeek maklumat ciri-ciri kereta tu:

*   **Apa Yang Kena Bagi (Input):** Bagi *prompt* kat model ni dengan semua ciri-ciri kereta yang korang nak ramal harganya. Contohnya, 'Ramal harga untuk kereta Proton X70, tahun 2020, perbatuan 60,000km, warna putih, kondisi baik di Lembah Klang.' Semakin spesifik maklumat, semakin tepatlah ramalannya.
*   **Apa DeepSeek Bagi Balik (Output):** DeepSeek akan proses input korang dan bagi jawapan ramalan harga. Kadang-kadang dia terus bagi nombor harga, kadang-kadang dalam bentuk ayat yang korang kena 'extract' nombor tu. Bersedia lah untuk interpret hasilnya ya.

*Macam ni rupanya:* Kat skrin korang akan terpapar satu *prompt* contoh. Contohnya, 'Berapa harga pasaran untuk Honda Civic 2018, 90,000km, automatic, warna hitam, keadaan tip-top, di Johor Bahru?'

## Soalan Lazim (FAQ)

*   **Q: Adakah DeepSeek-V2 ni percuma untuk digunakan?**
    A: DeepSeek ada versi API berbayar dan juga model yang boleh di-host secara lokal melalui Ollama. Untuk penggunaan API, biasanya ada had penggunaan percuma sebelum dikenakan bayaran. Kalau *host* lokal, korang cuma perlu tanggung kos hardware dan elektrik je.
*   **Q: Data apa yang paling penting untuk ramalan harga kereta?**
    A: Semua data penting, tapi jenama, model, tahun, perbatuan, dan kondisi kereta selalunya menjadi faktor utama. Lokasi jualan pun main peranan penting sebab harga mungkin berbeza ikut negeri atau kawasan.
*   **Q: Berapa lama masa yang diambil untuk *fine-tuning* model DeepSeek?**
    A: Ia bergantung pada saiz set data korang dan spesifikasi hardware yang digunakan (kalau *host* lokal). Untuk set data yang kecil, mungkin ambil beberapa jam saja. Untuk set data yang besar, boleh jadi berhari-hari. Tapi untuk permulaan, korang boleh cuba dengan subset data dulu.
*   **Q: Adakah DeepSeek boleh ramal harga kereta klasik atau unik?**
    A: DeepSeek boleh cuba, tapi ketepatannya sangat bergantung pada ketersediaan data sejarah jualan untuk kereta jenis tu. Kalau data sikit atau tak ada, ramalan mungkin tak berapa tepat. Ia paling sesuai untuk kereta yang ada banyak data di pasaran.
*   **Q: Apa beza DeepSeek dengan platform ramalan harga kereta sedia ada?**
    A: DeepSeek ni lebih fleksibel dan boleh disesuaikan (customizable) sepenuhnya dengan data tempatan dan faktor unik Malaysia. Platform sedia ada mungkin gunakan model generik yang kurang spesifik untuk pasaran kita, atau data mereka mungkin tak *up-to-date*.
