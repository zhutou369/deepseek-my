## Mencipta Skrip Automasi Login DeepSeek Web

Sekarang, jom kita mula tulis skrip Python yang akan buat kerja login secara automatik. Kita guna Selenium untuk buka browser, pergi ke laman login DeepSeek (https://chat.deepseek.com/), isi form login, dan klik butang login tu.

**Langkah 2.1: Tulis Kod Asas Skrip**

Buka text editor favourite korang (macam VS Code atau Notepad++) dan copy-paste kod ni. Gantikan `"username_anda"` dengan username DeepSeek korang yang betul, sama juga dengan `"password_anda"`. Ingat eh, simpan username/password terus dalam kod ni tak berapa selamat sangat kalau nak guna untuk projek besar, tapi untuk tutorial ni dah cukup. Kalau nak lagi secure, better guna environment variables atau fail config asing.

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.chrome.service import Service
from selenium.webdriver.chrome.options import Options
import time

# Konfigurasi WebDriver
chrome_options = Options()
# chrome_options.add_argument("--headless") # Buka dalam mod tanpa kepala (tanpa paparan GUI)

# Pastikan path ke chromedriver betul
service = Service(executable_path='./chromedriver.exe') # Gantikan dengan path sebenar jika perlu

driver = webdriver.Chrome(service=service, options=chrome_options)

# URL login DeepSeek
driver.get("https://chat.deepseek.com/login")

time.sleep(5) # Beri masa untuk halaman dimuatkan sepenuhnya

# Cari elemen username dan password, kemudian masukkan kelayakan
# Ini mungkin perlu diselaraskan berdasarkan ID/nama elemen sebenar di laman DeepSeek
try:
    username_field = driver.find_element(By.ID, "username") # Gantikan ID "username" jika berbeza
    password_field = driver.find_element(By.ID, "password") # Gantikan ID "password" jika berbeza
    login_button = driver.find_element(By.XPATH, "//button[@type='submit']") # Mungkin perlu diselaraskan

    username_field.send_keys("username_anda")
    password_field.send_keys("password_anda")
    login_button.click()

    time.sleep(10) # Beri masa untuk login selesai dan halaman seterusnya dimuatkan

    print("Login berjaya!")

except Exception as e:
    print(f"Ralat semasa login: {e}")
    print("Pastikan ID elemen betul atau laman web telah berubah.")
    # Untuk membantu troubleshoot, anda boleh rujuk panduan penyelesaian masalah login DeepSeek di sini:
    # [DeepSeek Web Login Troubleshooting](/posts/deepseek-web-login-troubleshoot/)

# Anda kini sudah login. Boleh lakukan operasi lain atau tutup pelayar.
# driver.quit() # Tutup pelayar selepas selesai
```

**Langkah 2.2: Mengenalpasti Elemen HTML**

Supaya kod kat atas tu jalan, korang kena tahu ID atau XPath untuk medan username, password, dan butang login kat website DeepSeek tu. Korang boleh guna 'Inspect Element' (klik kanan > Inspect) dalam browser untuk cari info ni. Ini penting gila sebab website selalu berubah, jadi korang mungkin kena update skrip dari masa ke masa.

## Mengkonfigurasi Proksi dalam Skrip Anda

Guna proksi ni memang penting, terutamanya kalau korang kerja dalam rangkaian tertentu, atau nak pantau trafik masuk keluar untuk jaga privasi data atau akses. Dengan proksi, semua trafik web korang boleh lalu server proksi dulu sebelum sampai ke DeepSeek. Ini memang best untuk PKS yang nak seragamkan akses internet staf diorang atau kawal penggunaan resource macam [DeepSeek API Key dan Had Penggunaannya](/posts/deepseek-api-key-and-limits/). Nampak tak faedahnya kat situ?

**Langkah 3.1: Tambah Konfigurasi Proksi ke Skrip**

Nak tambah proksi dalam Selenium, korang kena adjust sikit kod `chrome_options` tu. Tukar `"your_proxy_ip:port"` dengan IP dan port proksi korang yang betul. Kalau proksi korang perlukan authentication, itu cerita lain sikit; korang kena guna library Python lain atau setup proksi global kat sistem operasi korang.

```python
# ... kod sebelumnya

chrome_options = Options()
# chrome_options.add_argument("--headless") # Buka dalam mod tanpa kepala

# Konfigurasi proksi
PROXY = "your_proxy_ip:port" # Contoh: "192.168.1.1:8080" atau "proxy.example.com:3128"
chrome_options.add_argument(f'--proxy-server={PROXY}')

# Jika proksi memerlukan pengesahan (authentication), ia lebih kompleks.
# Anda mungkin perlu menggunakan pustaka seperti selenium-wire atau mengkonfigurasi proksi di OS.

service = Service(executable_path='./chromedriver.exe')
driver = webdriver.Chrome(service=service, options=chrome_options)

# ... sambungan kod login
```

Penjimatan masa yang kecil setiap kali login itu sebenarnya terkumpul menjadi banyak dalam jangka masa panjang. ## Tips-tips Extra Supaya Skrip Korang Lagi Mantap!

*   **Hendali Captcha/MFA:** Kalau DeepSeek buat Captcha atau Multi-Factor Authentication (MFA), skrip auto macam ni memang tak boleh handle terus. Korang kena fikirkan cara manual atau sambung dengan servis pihak ketiga untuk MFA tu. Tapi, kalau korang faham [DeepSeek Prompt Basics](/posts/deepseek-prompt-basics/) pun dah kira satu kelebihan untuk buat interaksi lebih 'ngam' lepas login.
*   **Mod Tanpa Kepala (Headless Mode):** Untuk guna kat server atau mana-mana tempat yang takde GUI, korang boleh on kan `headless mode` dalam `chrome_options`. Jadi, Chrome akan jalan kat belakang tabir tanpa tunjuk browser, dan ini jimatkan resource sistem.
*   **Kemas Kini Driver:** Sentiasa update ChromeDriver korang tau, biar sama dengan versi Chrome. Kalau tak matching, nanti skrip boleh 'meragam' tak jalan.
*   **Error Handling:** Masukkan lagi banyak blok `try-except` untuk handle macam-macam error, contohnya kalau elemen tak jumpa atau ada masalah network. Ini akan buat skrip korang lagi 'kental'.
*   **Pengurusan Kelayakan:** Tolong jangan sesekali simpan username dan password secara direct dalam kod korang kalau untuk projek live. Gunalah environment variables, fail `.env`, atau sistem pengurusan rahsia (secret management system) untuk data korang lebih selamat.

## Soalan-soalan yang Selalu Ditanya (FAQ)

**S1: Adakah selamat untuk mengautomatikkan login saya?**

Biasanya, okay je, asalkan korang ambil langkah berjaga-jaga. Make sure skrip tu simpan kat tempat selamat, dan username/password korang tak terdedah. Guna `environment variables` lagi bagus daripada tulis terus dalam kod. Sentiasa berwaspada dengan apa-apa yang melibatkan auto-login ni.

**S2: Skrip saya tidak berfungsi. Apa yang perlu saya semak dahulu?**

First sekali, check `chromedriver.exe` korang tu betul tak versinya, dan ada kat tempat yang skrip boleh 'nampak'. Second, double-check `ID` atau `XPath` untuk medan input (username, password) dan butang login. Website selalu berubah, jadi elemen-elemen ni mungkin kena update. Jangan lupa tengok mesej error kat Python console untuk clue. Kalau masih buntu, mungkin boleh jenguk panduan troubleshooting untuk masalah login biasa.

**S3: Bolehkah saya menggunakan skrip ini untuk platform lain selain DeepSeek?**

Ya, cara dia sama je. Korang cuma perlu ubah URL, `ID` atau `XPath` elemen login, dan apa-apa logik tambahan yang platform lain tu nak. Setiap website ada struktur HTML dia sendiri, jadi korang kena 'inspect' elemen untuk setiap satu.

**S4: Bagaimana jika saya mempunyai proksi yang memerlukan username dan password?**

Ha, yang ni memang sikit 'leceh' sikit kalau guna Selenium biasa. Korang kena pakai library pihak ketiga macam `selenium-wire` yang boleh set proksi dengan authentication terus dalam kod. Atau, alternatif lain, korang set je proksi tu kat level sistem operasi sebelum run skrip Python korang.

**S5: Adakah DeepSeek menyokong penggunaan API untuk automasi?**

Yeap, DeepSeek memang ada API yang super power untuk kita berinteraksi dengan model diorang terus, tak payah nak login web lagi.
