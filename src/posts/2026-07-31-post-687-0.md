Minimum 8GB VRAM diperlukan, tapi 12GB atau 16GB VRAM ke atas adalah lagi cun. Contohnya, NVIDIA RTX 3060 atau lebih tinggi akan bagi pengalaman yang baik. Pastikan driver kad grafik korang sentiasa terkini ya.
*   **Storan:** SSD dengan sekurang-kurangnya 100GB ruang kosong untuk sistem operasi dan model AI. Model DeepSeek-R1 7B saja boleh makan beberapa gigabait.

### Keperluan Perisian:

*   **Sistem Operasi:** Windows Server 2026 (atau Windows 11/10 64-bit yang terkini). Pastikan ia dikemaskini sepenuhnya.
*   **Driver GPU:** Pastikan driver terkini dipasang untuk kad grafik korang. Ini kritikal untuk prestasi AI.

## Langkah Demi Langkah: Pasang DeepSeek-R1 di Windows Server 2026

Mari kita mula proses pemasangan. Kita akan gunakan Ollama, satu rangka kerja yang memudahkan proses menjalankan pelbagai model bahasa besar kat PC korang. Memang mesra pengguna, sesuai sangat untuk orang baru dalam dunia AI tempatan ni.

### Langkah 1: Sediakan Pelayan Windows Server 2026 Anda

Pastikan Windows Server 2026 korang dah update sampai habis. Pergi ke `Settings` > `Windows Update` dan pasang sebarang kemas kini yang tertangguh. Lepas tu, pastikan `Windows Defender Firewall` dikonfigurasi untuk benarkan trafik yang diperlukan, terutamanya kalau korang nak akses DeepSeek-R1 dari mesin lain dalam rangkaian korang.

Kalau korang guna `Remote Desktop` untuk akses pelayan, pastikan ia berfungsi dengan baik. Sistem operasi yang stabil tu penting untuk pemasangan AI yang berjaya, jadi jangan ambil mudah.

### Langkah 2: Pasang Ollama

Ollama ni alat yang membolehkan korang muat turun, jalankan, dan urus model bahasa besar dengan senang hati. Ia uruskan semua benda rumit kat belakang tabir, jadi korang boleh fokus guna AI je. Semasa saya mula-mula cuba memasang LLM secara tempatan beberapa tahun lepas, prosesnya sangat rumit dengan banyak pergantungan, tetapi Ollama mengubah segalanya menjadi sangat mudah. Memang lega bila ada tools macam ni!

1.  **Muat Turun Ollama:** Lawati laman web rasmi Ollama di [ollama.com](https://ollama.com/) dan muat turun pemasang untuk Windows. Korang akan nampak butang muat turun yang jelas kat halaman utama mereka.
2.  **Jalankan Pemasang:** Dah siap muat turun, jalankan fail `.exe` tu. Ikut je arahan kat skrin. Proses pemasangan memang sangat mudah, biasanya cuma klik 'Next' beberapa kali. Ollama akan dipasang sebagai perkhidmatan latar belakang kat Windows Server korang.
3.  **Sahkan Pemasangan:** Buka `Command Prompt` atau `PowerShell` sebagai pentadbir dan taip `ollama`. Kalau pemasangan berjaya, korang akan nampak senarai arahan Ollama yang tersedia. Ini bermakna Ollama dah sedia untuk digunakan!

Untuk maklumat lanjut tentang pemasangan Ollama, korang boleh rujuk kepada [panduan pemasangan Ollama tempatan kami](/posts/deepseek-ollama-local-setup/) untuk detail yang lebih mendalam.

### Langkah 3: Muat Turun dan Jalankan DeepSeek-R1

Sekarang, bila Ollama dah terpasang, kita boleh dengan mudah muat turun dan jalankan model DeepSeek-R1 7B Instruct.

1.  **Buka Command Prompt/PowerShell:** Pastikan korang berada dalam Command Prompt atau PowerShell.
2.  **Muat Turun Model:** Taip arahan berikut untuk muat turun model DeepSeek-R1 7B Instruct:
    ```bash
    ollama pull deepseek-coder:7b-instruct
    ```
    Proses ini akan ambil masa sikit bergantung kelajuan internet korang, sebab saiz model ni beberapa gigabait. Korang akan nampak bar kemajuan tunjukkan status muat turun.
3.  **Jalankan Model:** Dah siap muat turun, korang boleh mula berinteraksi dengan DeepSeek-R1 dengan arahan:
    ```bash
    ollama run deepseek-coder:7b-instruct
    ```
    Korang akan nampak prompt yang sedia untuk terima input korang. Sekarang bolehlah tanya soalan atau bagi arahan kat DeepSeek-R1 terus dari terminal korang.

### Langkah 4: Uji dan Konfigurasi

Bila model dah jalan, cuba bagi beberapa prompt mudah untuk uji fungsinya. Contohnya:

*   `Apa itu kecerdasan buatan?`
*   `Tuliskan puisi pendek tentang Malaysia.`
*   `Bagaimana cara memasak nasi lemak?`

Korang akan nampak DeepSeek-R1 bagi respons. Kalau korang nak konfigurasi Ollama untuk diakses dari komputer lain dalam rangkaian korang, korang perlu ubah suai pemboleh ubah persekitaran `OLLAMA_HOST` pada pelayan. Contohnya, tetapkan ia kepada `0.0.0.0:11434` untuk benarkan akses dari mana-mana IP dalam rangkaian korang (pastikan firewall benarkan trafik pada port 11434).

Untuk dapatkan hasil terbaik daripada DeepSeek-R1, penting untuk faham [asas menulis prompt yang berkesan](/posts/deepseek-prompt-basics/). Ini akan bantu korang dapatkan jawapan yang lagi tepat dan relevan dari model.

## Mengatasi Cabaran Biasa

Ada kalanya korang mungkin akan hadapi beberapa isu kecil masa proses pemasangan atau masa guna DeepSeek-R1 ni. Jangan risau, ini beberapa cabaran biasa dan cara nak atasinya:

*   **Masalah Memori GPU:** Kalau model tak boleh load atau jalan terlalu perlahan, kemungkinan besar masalah VRAM GPU. Pastikan GPU korang cukup keperluan minimum (8GB VRAM) atau cuba kurangkan penggunaan VRAM oleh aplikasi lain. Tutup je aplikasi grafik berat yang tak diperlukan.
*   **Driver GPU Lama:** Driver kad grafik yang dah lapuk boleh timbulkan masalah prestasi atau tak serasi. Sentiasa pastikan korang guna driver GPU terkini dari laman web pengeluar (NVIDIA atau AMD).
*   **Ralat Rangkaian:** Kalau korang ada masalah muat turun model, check sambungan internet pelayan korang. Kalau korang cuba akses Ollama dari komputer lain, pastikan firewall pelayan benarkan sambungan kat port 11434 dan `OLLAMA_HOST` ditetapkan dengan betul.
*   **Model Lambat:** Selain masalah memori GPU, CPU yang kurang power atau RAM yang tak cukup juga boleh lambatkan pemprosesan. Walaupun Ollama cuba guna GPU sepenuhnya, sesetengah bahagian masih bergantung kat CPU dan RAM. Kalau prestasi masih tak memuaskan, mungkin dah tiba masanya untuk upgrade perkakasan.

## Soalan Lazim (FAQ)

Jom kita jawab beberapa soalan panas yang mungkin ada dalam fikiran korang!

### S1: Bolehkah saya jalankan DeepSeek-R1 tanpa kad grafik (GPU)?

Jawapan: Secara teori, boleh je, korang boleh cuba jalankan guna CPU sahaja. Tapi, prestasinya akan jadi sangat-sangat perlahan dan tak praktikal untuk kebanyakan kegunaan. Model 7B ni memang sangat bergantung pada kuasa pemprosesan selari GPU untuk bagi respons yang pantas.

### S2: Adakah DeepSeek-R1 percuma untuk digunakan?

Jawapan: Ya, DeepSeek-R1 boleh digunakan secara percuma untuk tujuan komersial dan penyelidikan, tertakluk kepada terma lesen model tersebut. Ini menjadikannya pilihan yang menarik berbanding model berbayar lain, dan berbeza dengan [panduan kami untuk memahami had penggunaan API](/posts/deepseek-api-key-and-limits/) untuk perkhidmatan awan yang mungkin melibatkan kos.

### S3: Berapa banyak ruang cakera yang diperlukan untuk DeepSeek-R1?

Jawapan: Model DeepSeek-R1 7B Instruct perlukan kira-kira 4-5 GB ruang cakera. Korang juga perlukan ruang tambahan untuk Ollama itu sendiri dan sebarang model lain yang mungkin korang muat turun nanti. Jadi, sediakanlah sekurang-kurangnya 100GB ruang kosong pada SSD korang untuk lebih selesa.

### S4: Bolehkah saya guna DeepSeek-R1 untuk tugas bahasa Melayu?

Jawapan: DeepSeek-R1, macam kebanyakan model bahasa besar, kebiasaannya dilatih guna data Bahasa Inggeris. Ia boleh faham dan hasilkan teks Bahasa Melayu pada tahap yang munasabah, tapi mungkin tak sebaik model yang dilatih khusus dalam Bahasa Melayu. Walaupun begitu, untuk tugas-tugas generik atau terjemahan, ia boleh jadi alat yang berguna.

### S5: Bagaimana cara nak update model DeepSeek-R1?

Jawapan: Untuk update model, korang boleh guna arahan `ollama pull deepseek-coder:7b-instruct` sekali lagi. Ollama akan check kalau ada versi yang lebih baru dan muat turunnya jika ada. Korang juga boleh buang model lama dengan `ollama rm deepseek-coder:7b-instruct` sebelum muat turun versi baru, tapi biasanya tak perlu pun.
