#### Langkah 1: Pilih Penyedia Perkhidmatan

Beberapa nama besar dalam arena GPU cloud termasuk AWS, Google Cloud, Azure, dan NVIDIA. Mereka ini mengkhususkan diri dalam menawarkan GPU pada harga yang lebih berpatutan, terutamanya untuk beban kerja AI dan pembelajaran mendalam. Untuk pilihan yang lebih mudah dikendalikan secara tempatan, pertimbangkan juga Vultr atau DigitalOcean yang mungkin tidak spesifik GPU tetapi menawarkan pelayan yang boleh di'customize' dengan kad grafik yang lebih baik jika ada pilihan.

#### Langkah 2: Konfigurasi Pelayan dan Pasang DeepSeek

Setelah memilih penyedia dan jenis GPU, anda perlu mengkonfigurasi pelayan anda. Kebanyakan penyedia akan memberi anda akses SSH ke mesin Linux. Dari situ, anda boleh pasang perisian yang diperlukan. Untuk DeepSeek Full Model, cara paling mudah untuk menjalankannya adalah melalui [Ollama](https://ollama.com/) ataupun `vLLM` jika anda mahukan prestasi yang lebih tinggi dan kawalan API. Ollama membolehkan anda memuat turun dan menjalankan model dengan arahan yang sangat mudah:

1.  **Sambung ke pelayan melalui SSH:** `ssh user@your_server_ip`
2.  **Pasang Docker (jika belum ada) dan Ollama:** Ikut arahan di laman web rasmi Ollama. Biasanya melibatkan `curl -fsSL https://ollama.com/install.sh | sh`.
3.  **Muat turun dan jalankan DeepSeek:** Dengan Ollama, anda boleh mencari model DeepSeek yang tersedia, contohnya, `ollama pull deepseek-coder:33b` atau versi yang anda inginkan. Pastikan ia adalah 'Full Model' yang anda cari.

Sekiranya anda ingin menjalankan model DeepSeek secara tempatan menggunakan Ollama, kami ada panduan yang lebih terperinci. [Lihat panduan DeepSeek Ollama setup di sini](/posts/deepseek-ollama-local-setup/).

#### Langkah 3: Jalankan Model DeepSeek

Setelah model dimuat turun, anda boleh berinteraksi dengannya menggunakan arahan `ollama run deepseek-coder:33b` atau melalui API tempatan yang disediakan oleh Ollama. Anda boleh menulis skrip Python yang ringkas untuk menghantar ‘prompt’ dan menerima jawapan. Ini membolehkan anda mengintegrasikan DeepSeek ke dalam aplikasi anda mahupun menggunakannya untuk tujuan penyelidikan. Pastikan anda faham asas 'prompt' untuk dapatkan hasil terbaik dari model. [Belajar asas 'prompt' DeepSeek di sini](/posts/deepseek-prompt-basics/).

```bash
# Contoh arahan run di terminal setelah model dimuat turun
ollama run deepseek-coder:33b

# Contoh menggunakan API (dalam Python)
import requests
url = "http://localhost:11434/api/generate"
headers = {"Content-Type": "application/json"}
data = {"model": "deepseek-coder:33b", "prompt": "Tulis kod Python untuk mencari nombor perdana.", "stream": False}
response = requests.post(url, headers=headers, json=data)
print(response.json()['response'])
```

## Soalan Lazim (FAQ)

### Q1: Adakah DeepSeek Full Model berat sangat?

Ya, versi penuh DeepSeek (misalnya 33B ke atas) memang memerlukan sumber komputasi yang besar, terutamanya dari segi VRAM (Video RAM). Ini sebab saiz model itu sendiri yang boleh mencecah puluhan gigabait, menjadikannya mustahil untuk dijalankan pada kad grafik biasa.

### Q2: Bolehkah saya guna GPU on-premise saya?

Kalau anda ada kad grafik gred tinggi dengan VRAM yang mencukupi (contoh: NVIDIA RTX 3090 dengan 24GB VRAM, atau lebih baik A6000/A100), ya, anda boleh. Tapi, ini memerlukan pelaburan awal yang besar dan kepakaran teknikal untuk persediaan dan penyejukan.

### Q3: Bagaimana nak pantau penggunaan kos?

Kebanyakan penyedia cloud ada dashboard atau konsol kawalan yang tunjukkan penggunaan sumber dan anggaran bil anda secara masa nyata. Sentiasa semak dashboard ini untuk mengelakkan bil yang tinggi. Anda juga boleh tetapkan bajet atau had penggunaan pada beberapa platform.

### Q4: Perlukah saya ada kemahiran pengaturcaraan?

Untuk run model guna Ollama, kemahiran asas Linux command line dan mungkin sedikit Python sangat membantu. Jika anda guna DeepSeek API terus, kemahiran pengaturcaraan untuk hantar permintaan HTTP adalah diperlukan.

### Q5: Apa beza DeepSeek 7B dengan Full Model?

DeepSeek 7B adalah versi model yang lebih kecil dan ringan, memerlukan VRAM yang jauh lebih sedikit dan boleh dijalankan pada hardware yang kurang berkuasa. 'Full Model' biasanya merujuk kepada versi terbesar (misalnya 33B, 67B) yang tawarkan prestasi dan kefahaman yang lebih baik tapi memerlukan sumber yang sangat besar.
